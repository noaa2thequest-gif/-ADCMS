🔧 Setup ADCMS Pro with Google Sheets

ℹ️ Follow these steps to connect your Google Sheet to ADCMS Pro
  1. 1. Create a Google Sheet

    Go to Google Sheets and create a new sheet named "ADCMS Pro"

  2. 2. Create Sheet Tabs

    Create these tabs in your sheet:

    Defects | MEL Items | Spare Parts | Maintenance Log
  3. 3. Get Sheet ID

    Copy the Sheet ID from the URL:

    https://docs.google.com/spreadsheets/d/[SHEET_ID]/edit
  4. 4. Enable Google Sheets API

    Go to Google Cloud Console and enable the Sheets API

  5. 5. Create API Key

    Create an API key in Google Cloud Console

  6. 6. Share Your Sheet

    Share your Google Sheet with "Anyone with the link" access
